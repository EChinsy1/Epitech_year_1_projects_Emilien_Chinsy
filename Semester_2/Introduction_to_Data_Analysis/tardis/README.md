### Goal:
The goal of this project was to write a prediction model that predicts the tardiness of trains using a dataset from 2018 to 2025 from the SNCF.

### Installation
The `requirements.txt` contains all the libraries the code needs, you can install everything by going in a virtual environment and using
```
pip install -r requirements.txt
```

### Usage
First run the tardis_model.ipynb notebook to train the model.
Then run the dashboard using streamlit run tardis_dashboard.py
To use the model, you can run if directly from the dashboard, in the model page.

Simply input the two stations, the date and if the journey is purely in france or international, click predict and await the result.
